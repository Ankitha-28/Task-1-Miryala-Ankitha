# To-Do List System

## Project Overview

The To-Do List System is a Python-based application developed as part of the DecodeLabs Industrial Training Program. The project allows users to create, manage, and organize daily tasks efficiently. It demonstrates the use of fundamental Python programming concepts such as lists, dictionaries, loops, conditional statements, user input handling, and basic data management.

## Objective

The objective of this project is to understand how to store and manage multiple pieces of information using Python lists and dictionaries while implementing the IPO (Input-Process-Output) model.

### Input

* User enters task details through the menu-driven interface.
* User selects options such as Add Task, View Tasks, Delete Task, or Exit.

### Process

* The program stores tasks in a list.
* Each task is assigned a unique ID using a dictionary.
* Tasks can be viewed, managed, and deleted based on user actions.

### Output

* Displays confirmation messages when tasks are added or deleted.
* Shows the complete list of tasks stored in the system.
* Provides menu options and status updates to the user.

## Features

* Add new tasks to the to-do list.
* View all saved tasks.
* Delete completed or unwanted tasks.
* Store multiple tasks using lists.
* Assign unique IDs to tasks using dictionaries.
* Interactive menu-driven interface.
* Handles invalid user input gracefully.

## Technologies Used

* Python 3.x

## Concepts Implemented

* Lists
* Dictionaries
* User Input and Output
* Loops (while loop, for loop)
* Conditional Statements (if-elif-else)
* List Operations (append, remove)
* Data Management
* Basic Exception Handling

## Project Workflow

1. Create an empty list to store tasks.
2. Display a menu with available options.
3. Accept user input for the desired operation.
4. Add new tasks to the list using `append()`.
5. Display all tasks using a loop.
6. Delete tasks based on the selected task ID.
7. Repeat until the user chooses to exit.

## How to Run the Project

1. Install Python 3.x.

2. Download or create the project file `main.py`.

3. Open a terminal or command prompt.

4. Navigate to the project directory.

5. Run the following command:

   ```bash
   python main.py
   ```

6. Select options from the menu to manage tasks.

7. Choose Exit to close the application.
